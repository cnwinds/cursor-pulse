# 可选 IM 机器人命令（钉钉 / 飞书）

小脉支持自然语言对话。直接用口语描述即可，例如「帮我绑定 Cursor Key」「这个月花了多少」「有哪些功能」。

下文命令示例仅供参考，**不是固定口令**。询问「帮助」时，机器人会根据当前可见技能动态总结。

技能说明：`assistant_platform/skills/docs/`。管理后台「技能一览」可预览，修改请改仓库并发版。

本产品 **只服务 Cursor**：用量靠绑定 API Key 自动同步。IM **不**接受 CSV / 截图 / 其他厂商用量上报。

---

## 使用前须知

### 账期

未写明账期时，默认指当前统计账期（通常为当月，`YYYY-MM`）。

### 使用场景

| 场景 | 建议方式 | 说明 |
|------|----------|------|
| 绑定 / 解绑 Cursor Key | **私聊** | 勿在群内发送 Key |
| 借 Key / 归还 Key | **私聊** | 自助为 `pka_` 代理别名 |
| 查本人用量 / 额度 | 私聊 | |
| 分享心得 | 私聊或群 | 收录进团队知识库 |

### 权限

| 角色 | 典型能力 |
|------|----------|
| 普通成员 | 绑定 Key、查本人用量、自助借 Key |
| 管理员 | 台账 owner/operator 或 `ADMIN_CHANNEL_USER_IDS`：成员管理、代分配借用等 |

---

### 绑定工作群（管理员）

将机器人拉入目标群后，在群内 **@ 机器人** 并发送：`启动`（同义：`激活` / `start`）。

作用：将当前群设为工作群；配置写入团队设置。更换工作群仅管理员可操作。

---

## 一、Cursor 用量（自动同步）

> 绑定 User API Key 后系统自动同步，**无需** CSV 或截图。

### 绑定

```
绑定 cursor key crsr_xxxxxxxx
```

多名下多账号时需带邮箱：

```
绑定 cursor key crsr_xxxxxxxx 到 alice@company.com
```

### 解绑 / 查询

```
解绑 cursor key
我的用量
额度
```

Web 管理后台「账号台账」亦可绑定与同步。

---

## 二、借 Key

额度告警/耗尽且存在可借出富余账号时，可自助申请：

```
借 key
申请 key
归还 key
```

交付默认为代理别名 `pka_`（需配置 `HTTPS_PROXY`）。管理员也可在 Web「借用记录」代分配。

---

## 三、技巧知识库

```
心得：……
技巧：……
```

整理后写入团队知识库；管理员可在 Web「技巧知识库」查看。
