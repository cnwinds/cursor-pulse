# Cursor Pulse 品牌资源 / Brand Assets

## 设计概念

Logo 由两部分构成：**鼠标指针（Cursor）** 与从指针尖向外扩散的**脉冲波纹（Pulse）**，
呼应产品名 "Cursor Pulse" —— 实时感知每一次 Cursor 用量的脉动。
渐变色 `#38bdf8 → #6366f1` 与 Web 控制台（web-admin）的品牌色一致。

## 文件清单 / Files

| 文件 | 用途 |
| --- | --- |
| `logo-mark.svg` | 主图标（渐变圆角方块），用于 favicon、应用内品牌位、社交头像 |
| `logo-mark-mono-dark.svg` | 单色深底版（`#0f172a`），用于无法使用渐变的场景 |
| `logo-mark-mono-white.svg` | 纯白图形（无底），用于深色背景上的单色印刷/压印 |
| `logo-horizontal.svg` | 横版组合（图标 + 双色字标），浅色背景用 |
| `logo-horizontal-dark.svg` | 横版组合，深色背景用 |
| `logo-mark-512.png` / `logo-mark-256.png` | PNG 导出版 |
| `logo-horizontal-1120.png` | 横版 PNG 导出，README / 文档头图 |

## 色板 / Palette

- Sky `#38bdf8` → Indigo `#6366f1`（135° 渐变）
- 深色底 `#0f172a`
- 字标：`Cursor` 深色底上用 `#0f172a`（浅底）/ `#ffffff`（深底），`Pulse` 用 `#6366f1`（浅底）/ `#38bdf8`（深底）

## 使用建议

- 最小展示尺寸：图标 16px（favicon 已验证可读），横版 120px 宽
- 图标周围保留不少于图标宽度 25% 的留白
- 不要旋转、拉伸或更改渐变方向
